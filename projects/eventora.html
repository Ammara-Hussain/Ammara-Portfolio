Eventora

A Java and JavaFX desktop project developed to apply Object-Oriented Programming concepts.

Overview

Eventora was developed as part of my Object-Oriented Programming coursework. The project was built in Java using JavaFX for the graphical user interface.

Technologies

  • Java
  • JavaFX
  • IntelliJ IDEA
  • Object-Oriented Programming

Development Approach

The project was designed using object-oriented programming principles. Java was used for the application logic while JavaFX was used to create the desktop graphical interface.

What I Learned

Eventora helped me strengthen my understanding of classes, objects and object-oriented software development while also giving me practical experience with JavaFX.

Development Environment

The project was developed using IntelliJ IDEA.
