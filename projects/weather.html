WEB DEVELOPMENT

Weather Forecast Web App

A mini weather application built using HTML, CSS and JavaScript with a weather API.

Overview

This project was developed as a small web development project to practice front-end development and working with an external API.

Technologies

  • HTML
  • CSS
  • JavaScript
  • Weather API

How It Works

The application uses JavaScript to communicate with a weather API and retrieve weather data. The retrieved information is then displayed through the web interface.

What I Learned

This project helped me practice HTML and CSS for interface structure and styling, JavaScript for application logic, and API integration for retrieving external data.

Challenges

One of the main learning points was understanding how a web application communicates with an external API and uses the returned data.
