SOFTWARE DESIGN & ARCHITECTURE

Automated Islamic Inheritance Calculation System

A Java and JavaFX software project developed to automate Islamic inheritance calculations while applying software design concepts.

Overview

This project was developed as part of a Software Design and Architecture course. The system focuses on automating inheritance calculations based on the information provided by the user.

Technologies

  • Java
  • JavaFX
  • IntelliJ IDEA
  • Software Design and Architecture

Purpose

The purpose of the system is to provide a structured way of calculating Islamic inheritance shares and reduce the need for manual calculations.

Software Engineering Focus

The project allowed me to apply software design and architecture concepts to a real-world, domain-specific problem.

What I Learned

Through this project, I gained experience in translating domain requirements into software functionality and applying software design principles using Java and JavaFX.

Development Environment

The project was developed using Java, JavaFX and IntelliJ IDEA.
